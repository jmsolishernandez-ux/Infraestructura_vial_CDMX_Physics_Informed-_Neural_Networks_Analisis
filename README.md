# Infraestructura_vial_CDMX_Physics_Informed-_Neural_Networks_Analisis
"Análisis integral de infraestructura vial en CDMX (2020-2026) utilizando Physics-Informed Neural Networks (PINNs) para modelado de deterioro."
Modelo tiene un IC (Indice de Confiabilidad) del 90% y que detectó el umbral de intervención mayor en 2021.
Tecnologías: PyTorch, Pandas, Scikit-Learn.
Hallazgo Estrella: valor de $\gamma=0.957$, que demuestra cómo la lluvia casi duplica el deterioro del pavimento.
